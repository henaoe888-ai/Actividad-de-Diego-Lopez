Nombre del Proyecto: Registro_de_Productos

Descripciòn: se creo esta aplicaciòn web a traves de python y utilizando el framework "django" ,de manera en la que pudiesemos registrar un producto con sus caracteristicas y mandar esos datos que se ingresaron a la base de datos,se puede modificar, agregar màs productos y por ùltimo eliminarlo si asi se desea.


tecnologìas usadas: Python, Django, SQLite,HTML,Git y Github

Ejecuciòn del proyecto:

1* Se crea el entorno virtual y se activa

2* Installar django y asegurarnos en el entorno virtual (venv) de que si se halla instalado

3* Tener y poner en ejecuciòn de los comandos para poder emigrar, es decir ordenar a la base de datos que cree una tabla que en este caso es productos

-python manage.py makemigrations
-python manage.py migrate
